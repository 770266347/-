# 小游戏发行准备

## 当前策略

《垃圾收集者》先保持 Godot 内 PC 可测试，同时把项目约束调到更接近 Web/小游戏发行的方向。

- 渲染：使用 Compatibility，降低 WebGL/小游戏适配风险。
- 输入：开启鼠标和触摸互相模拟，PC 鼠标测试与触屏点击都走同一套按钮逻辑。
- 存档：`SaveManager` 不直接碰平台细节，统一经过 `PlatformBridge`。
- 布局：先按 iPhone 16 竖屏物理分辨率 `1179x2556` 做轻量响应式，顶部资源栏、中间瓶子区域、底部购买面板。

## 后续不要散落到玩法代码里的东西

- 登录态
- 分享
- 激励视频广告
- 排行榜
- 云存档
- 充值或平台商品
- 小程序生命周期事件

这些都先放到 `PlatformBridge`，如果后续变复杂，再拆成 `scripts/platform/` 下的独立适配器。

## 建议开发顺序

1. 在 Godot 里继续做 PC 版核心循环，保持 `Main.tscn` 一键可运行。
2. 尽早导出一次 Web 版本，确认 Compatibility 渲染、字体、存档和输入都能跑。
3. 再选具体小游戏平台，接对应外壳或 SDK。
4. 当前项目按竖屏准备，如果后续改横屏，应先重做 HUD、瓶子区域和底部购买面板。
5. 上线前把目标平台的真机加载速度、包体、字体、音频策略、存档策略单独测一轮。
