# 06_天赋系统需求点

## 1. 系统目标

天赋系统提供跨场景生效的长期成长路线。玩家通过累计回收获得天赋点，从中心节点开始，向上、右、下、左四个方向逐步加点。

## 2. 天赋点规则

- 天赋点根据累计回收物数量自动获得，不消耗现金。
- 每个天赋节点消耗 1 点。
- 当前版本共 13 个节点，最多获得 13 点。
- 里程碑为：`0、50、150、400、800、1500、3000、6000、12000、25000、50000、100000、200000` 件。
- 已获得点数、已使用点数和剩余点数都由累计回收数量与已点亮节点实时计算。
- 重置全部数据时，同时重置天赋节点。

## 3. 天赋网结构

```text
                  闪电拾取
                     |
                  连点节奏
                     |
                  熟练手法
                     |
垃圾浪潮 - 扎堆出现 - 货源增加 - 回收本能 - 轻装上阵 - 熟练分工 - 团队协作
                     |
                  回收热潮
                     |
                  满载加班
                     |
                  自动装袋
```

- 中心节点没有前置条件。
- 四个方向的第一个节点都要求先点亮中心节点。
- 同一方向的后续节点要求先点亮前一个节点。
- 不要求玩家点完一条分支后才能进入其他分支。
- 每个节点还必须满足一个指定产物的累计收集数量条件。

## 4. 节点效果

| 方向 | 节点 | 效果 |
|---|---|---|
| 中心 | 回收本能 | 按住场景连续拾取，每 0.8 秒收集 1 个最上层产物 |
| 上 | 熟练手法 | 连续拾取间隔缩短至 0.65 秒 |
| 上 | 连点节奏 | 连续手动拾取 5 次后，获得 3 秒拾取速度 +30% |
| 上 | 闪电拾取 | 连续拾取间隔缩短至 0.4 秒，点击去重间隔降低 30% |
| 右 | 轻装上阵 | 全部帮手移动速度 +10% |
| 右 | 熟练分工 | 全部帮手收集冷却 -15% |
| 右 | 团队协作 | 每名上阵帮手额外提供 2% 帮手效率，最多 +20% |
| 下 | 回收热潮 | 每 30 秒向当前场景额外生成 5 个产物 |
| 下 | 满载加班 | 当前场景库存达到 80% 时，帮手移动速度额外 +20% |
| 下 | 自动装袋 | 每实际收集 20 个产物，额外获得 1 个对应产物，不增加现金 |
| 左 | 货源增加 | 全部场景产物刷新间隔 -8% |
| 左 | 扎堆出现 | 生成产物时有 15% 概率额外生成 1 个 |
| 左 | 垃圾浪潮 | 当前场景产物少于容量 20% 时，刷新速度 +30% |

产品收集条件：

| 节点 | 额外条件 |
|---|---|
| 回收本能 | 收集塑料瓶 50 个 |
| 熟练手法 | 收集易拉罐 25 个 |
| 连点节奏 | 收集纸皮箱 20 个 |
| 闪电拾取 | 收集啤酒瓶子 50 个 |
| 轻装上阵 | 收集红酒瓶子 20 个 |
| 熟练分工 | 收集奶茶杯 100 个 |
| 团队协作 | 收集外卖盒 50 个 |
| 回收热潮 | 收集塑料瓶 500 个 |
| 满载加班 | 收集白酒瓶子 50 个 |
| 自动装袋 | 收集食用油瓶 50 个 |
| 货源增加 | 收集纸皮箱 100 个 |
| 扎堆出现 | 收集饮料瓶 100 个 |
| 垃圾浪潮 | 收集塑料桶 100 个 |

天赋收益与通用升级叠加，但刷新间隔不能低于基础间隔的 30%，帮手收集冷却不能低于基础冷却的 50%。

## 5. UI 需求

- 主界面底部页签顺序为 `升级、场景、帮手、天赋`。
- 四个页签等宽，新增天赋后原三个页签同步缩短。
- 天赋页签不显示升级子页签栏。
- 顶部显示可用天赋点、累计获得点数和下一个点的回收里程碑。
- 点击节点只展示天赋预览、效果和解锁条件，不立即加点。
- 按住节点达到 1 秒后才执行加点。
- 按住过程中发生拖动时取消本次加点，只移动天赋画布。
- 天赋网右上角提供 `重置` 按钮，重置后返还全部已使用天赋点，但不减少累计回收数量。
- 中心节点初始位于可视区域中央。
- 天赋网画布支持鼠标或触摸双向拖动。
- 从天赋节点上按住拖动时必须移动画布，超过拖动阈值后不能误加点。
- 轻点节点时显示效果、产品收集进度、前置条件和点数状态。
- 已点亮、当前可点和未满足条件的节点使用不同颜色。
- 四个方向使用不同颜色，连线颜色需要跟随节点状态变化。

## 6. 配置和存档

- 天赋配置位于 `data/talents.json`。
- 每个节点配置 ID、名称、说明、分支、网格坐标、点数消耗、前置节点、指定产物收集条件和效果。
- 存档记录已点亮天赋 ID，不单独保存天赋点余额。
- 旧存档没有天赋字段时按空天赋网加载，不影响原有资源和解锁内容。
- 配置删除无效节点后，读档时自动清理对应存档状态。

## 7. 验收需求

- 新存档拥有 1 个可用天赋点；累计收集 50 个塑料瓶后可以点亮中心节点。
- 未点亮中心节点时不能点亮四个分支节点。
- 累计回收达到里程碑后，可用天赋点立即增加。
- 点亮中心和上方分支后，玩家可以长按连续拾取，并逐步提高连续拾取速度。
- 点亮右方分支后，全部已上阵帮手移动更快、收集冷却缩短，并按上阵人数获得团队效率。
- 点亮下方分支后，当前场景会获得定时补货、满载加速和自动装袋效果。
- 点亮左方分支后，全部场景刷新更快，并有概率额外生成产物。
- 不满足产品收集条件时，即使前置节点已点亮，也不能继续加点。
- 点击节点后能看到当前效果、产品收集进度和点数状态。
- 轻点节点不会解锁，持续按住 1 秒才会解锁。
- 点击重置后所有节点恢复未点亮，天赋点恢复为可用状态。
- 切换场景、退出游戏和重新读档后，天赋效果仍然生效。
- 在节点上拖动时只移动天赋网，不会误点亮节点。
- iPhone 16 竖屏下四个主页签文字完整，天赋节点和文字不重叠。
