# 03_升级系统需求点

## 1. 系统目标

升级系统负责决定：

> 玩家花费现金后，解锁新场景、新的回收物产出，或提升已有回收物的收益效率。

第一版升级系统优先服务产物解锁，不先做复杂成长线。

## 2. 升级类型

第一版先做四类升级：

| 类型 | 作用 | 优先级 |
|---|---|---:|
| 场景解锁 | 解锁新的可切换场景 | 高 |
| 产物解锁 | 解锁某个场景的新产物 | 高 |
| 产物收益 | 提高某类产物现金收益 | 中 |
| 刷新效率 | 提高当前场景刷新效率 | 低 |

第一阶段建议先实现“场景解锁”和“产物解锁”。

## 3. 升级作用域与解锁需求

升级配置必须标明作用域：

| scope | 归属位置 | 生效范围 |
|---|---|---|
| global | 升级 > 通用 | 对全部场景生效 |
| scene | 升级 > 对应场景 | 只对指定场景生效 |
| scene_unlock | 场景主页签 | 负责解锁新场景 |

- `global` 升级不绑定场景，购买后所有已解锁和未来解锁的场景都能获得效果。
- `scene` 升级必须配置 `scene_id`，只能影响对应场景。
- 原有产物解锁全部属于 `scene`，放进对应场景的升级子页签。
- 场景解锁不放进升级子页签，继续放在主界面的 `场景` 页签。

- 每个可解锁场景对应一个升级项。
- 场景升级项购买后，该场景进入可切换场景列表。
- 场景升级项可以附带默认产物解锁。
- 每个可解锁产物对应一个升级项。
- 升级项购买后，产物进入对应场景的实际生成池。
- 已解锁的产物不能重复解锁。
- 未满足前置条件时，升级项不可购买。
- 现金不足时，升级项不可购买。
- 购买成功后立即生效。

## 4. 通用升级项

| 升级 ID | 名称 | 每级效果 | 最高等级 | 初始费用 | 费用成长 |
|---|---|---|---:|---:|---:|
| upgrade_global_value | 回收价 | 所有产物现金收益 +20% | 5 | 100 | 1.45 倍 |
| upgrade_global_spawn | 刷新效率 | 所有场景刷新间隔 -10% | 5 | 200 | 1.5 倍 |
| upgrade_global_capacity | 场地容量 | 所有场景后台库存上限 +300 | 5 | 400 | 2 倍 |

- 回收价满级时总收益为基础售价的 2 倍。
- 刷新效率满级时刷新间隔为基础间隔的 50%，即产出速度约为 2 倍。
- 场地容量满级时每个场景的后台库存上限增加 1,500。
- 升级按钮必须直接显示每级效果，避免玩家只能看到名称和费用。

通用升级费用按照以下规则计算：

```text
下一级费用 = 初始费用 × 费用成长 ^ 当前等级
```

## 5. 街道升级项

| 升级 ID | 名称 | 花费现金 | 解锁产物 | 前置条件 |
|---|---|---:|---|---|
| unlock_street_can | 解锁易拉罐 | 30 | 易拉罐 | 无 |
| unlock_street_cardboard | 解锁纸皮箱 | 100 | 纸皮箱 | 已解锁易拉罐 |

街道初始默认已解锁：

- 塑料瓶

## 6. 酒吧升级项

| 升级 ID | 名称 | 花费现金 | 解锁内容 | 前置条件 |
|---|---|---:|---|---|
| unlock_bar_scene | 解锁酒吧 | 250 | 酒吧场景、啤酒瓶子 | 无 |
| unlock_bar_wine | 解锁红酒瓶子 | 600 | 红酒瓶子 | 已解锁酒吧 |
| unlock_bar_baijiu | 解锁白酒瓶子 | 1,200 | 白酒瓶子 | 已解锁红酒瓶子 |

酒吧未解锁前不可切换进入。购买“解锁酒吧”后，酒吧默认产出啤酒瓶子；红酒瓶子和白酒瓶子仍通过后续升级解锁。

## 7. 后续场景升级项

| 场景 | 场景解锁费用 | 默认产物 | 后续产物升级费用 |
|---|---:|---|---|
| 夜市 | 1,800 | 奶茶杯 | 外卖盒 3,500；食用油瓶 7,000 |
| 海滩 | 9,000 | 饮料瓶 | 防晒霜瓶 16,000；塑料浮球 28,000；废弃渔网 50,000 |
| 工业园 | 40,000 | 塑料桶 | 铝制零件 75,000；废旧电线 130,000；铜制零件 220,000 |

场景解锁前置顺序：

```text
酒吧 -> 夜市 -> 海滩 -> 工业园
```

- 解锁场景后立即开放该场景的默认产物。
- 高价值产物继续在 `升级` 页签中逐级解锁。
- 玩家不需要买完前一场景的全部产物，但必须先解锁前一场景。

## 8. 产物收益升级需求

产物收益升级用于提高已解锁产物的现金收益。

第一版可以先预留，不一定马上实现。

示例：

| 升级 ID | 名称 | 效果 |
|---|---|---|
| upgrade_plastic_value | 塑料瓶回收价提升 | 塑料瓶现金收益 +1 |
| upgrade_can_value | 易拉罐回收价提升 | 易拉罐现金收益 +1 |
| upgrade_glass_value | 玻璃瓶回收价提升 | 酒吧瓶子现金收益 +5% |

## 9. 刷新效率升级需求

刷新效率升级用于提高产物出现速度。

第一版可以先预留，不一定马上实现。

示例：

| 升级 ID | 名称 | 效果 |
|---|---|---|
| upgrade_street_spawn | 街道巡回路线 | 街道刷新间隔 -5% |
| upgrade_bar_spawn | 酒吧回收合作 | 酒吧刷新间隔 -5% |
| upgrade_screen_capacity | 大号回收袋 | 后台库存上限增加 |

## 10. 升级显示需求

- 主界面下方显示页签栏。
- 页签栏包含 `升级`、`场景`、`帮手` 和 `天赋` 四个页签。
- `升级` 页签显示产物解锁和产物效率类按钮。
- `场景` 页签专门显示场景解锁按钮。
- 升级按钮尽量小，适合在竖屏底部集中显示。
- 升级按钮需要显示名称、花费、效果、状态。
- 已购买升级项显示为已解锁。
- 现金不足的升级项显示为不可购买。
- 未满足前置条件的升级项显示为锁定。
- 点击购买成功后，立即刷新升级面板。

### 10.1 升级页签需求

- `升级` 页签是默认打开页签。
- 点击 `升级` 后，下方显示横向可滚动子页签栏。
- 子页签顺序为 `通用`、`街道`、`酒吧`、`夜市`、`海滩`、`工业园`。
- 子页签总宽度超过显示区域时，支持按住空白区域或任意页签按钮左右拖动。
- 轻点页签执行切换，移动超过拖动阈值后只滚动页签栏，不触发切换。
- `通用` 子页签显示所有 `scope = global` 的升级。
- 各场景子页签只显示 `scene_id` 等于该场景 ID 的升级。
- 街道升级项显示街道产物解锁按钮。
- 酒吧升级项显示酒吧产物解锁按钮。
- 夜市、海滩和工业园的产物解锁按钮分别放在对应场景子页签。
- 场景解锁项不显示在 `升级` 页签中。
- 第一版按钮可以使用紧凑文本按钮，不强制做大卡片。

### 10.2 场景页签需求

- `场景` 页签只显示场景解锁按钮。
- 已解锁场景显示为已解锁。
- 未解锁但现金足够的场景可以购买。
- 现金不足的场景按钮不可购买。
- 场景购买成功后立即刷新页签状态，并允许通过主界面左右按钮切换。
- 场景页签按顺序显示“解锁酒吧”“解锁夜市”“解锁海滩”“解锁工业园”。

## 12. 存档需求

存档中需要记录：

- 已购买升级 ID 列表
- 已解锁场景 ID 列表
- 已解锁产物 ID 列表

默认已解锁产物：

```text
street_plastic_bottle
```

默认已解锁场景：

```text
street
```

## 13. 代码需求

需要支持：

- 升级配置读取。
- 按 `scope` 和 `scene_id` 筛选升级子页签内容。
- 判断升级项是否可购买。
- 购买升级项。
- 扣除现金。
- 记录已购买升级。
- 记录已解锁场景。
- 记录已解锁产物。
- 通知产物生成系统刷新生成池。
- 通用回收价通过统一现金结算入口生效。
- 通用刷新效率通过统一场景刷新入口生效。
- 通用场地容量通过统一后台库存上限入口生效，不直接增加画面节点预算。
- 保存和读取升级状态。

## 14. 验收需求

功能验收：

- 初始街道只会生成塑料瓶。
- 购买“解锁易拉罐”后，街道开始生成易拉罐。
- 购买“解锁纸皮箱”后，街道开始生成纸皮箱。
- 未购买“解锁酒吧”时，不能切换进入酒吧。
- 购买“解锁酒吧”后，可以切换进入酒吧，酒吧开始生成啤酒瓶子。
- 场景页签按顺序显示四个可解锁场景。
- 点击升级主页签后能看到通用和五个场景子页签。
- 通用子页签只显示三项通用升级。
- 每个场景子页签只显示该场景的产物解锁。
- 通用回收价升级后，所有场景的产物收益都提高。
- 通用刷新效率升级后，所有场景刷新都加快。
- 通用场地容量升级后，所有场景后台库存上限都增加，画面上限保持不变。
- 夜市、海滩、工业园必须满足前置场景条件才能购买。
- 新场景购买成功后，默认产物立即进入生成池。
- 现金不足时不能购买升级。
- 已购买升级不会重复扣费。

技术验收：

- 场景和产物解锁状态可存档。
- 读档后已解锁场景和产物仍然生效。
- 生成系统不直接写死可生成产物。
- Godot editor 加载无报错。
