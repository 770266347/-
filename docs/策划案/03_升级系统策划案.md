# 03_升级系统需求点

## 1. 系统目标

升级系统负责决定：

> 玩家花费现金后，解锁新场景、新的回收物产出，或提升已有回收物的收益效率。

第一版升级系统优先服务产物解锁，不先做复杂成长线。

## 2. 升级类型

第一版先做四类升级：

| 类型 | 作用 | 优先级 |
|---|---|---:|
| 场景解锁 | 解锁新的可切换场景 | 高 |
| 产物解锁 | 解锁某个场景的新产物 | 高 |
| 产物收益 | 提高某类产物现金收益 | 中 |
| 刷新效率 | 提高当前场景刷新效率 | 低 |

第一阶段建议先实现“场景解锁”和“产物解锁”。

## 3. 场景与产物解锁需求

- 每个可解锁场景对应一个升级项。
- 场景升级项购买后，该场景进入可切换场景列表。
- 场景升级项可以附带默认产物解锁。
- 每个可解锁产物对应一个升级项。
- 升级项购买后，产物进入对应场景的实际生成池。
- 已解锁的产物不能重复解锁。
- 未满足前置条件时，升级项不可购买。
- 现金不足时，升级项不可购买。
- 购买成功后立即生效。

## 4. 街道升级项

| 升级 ID | 名称 | 花费现金 | 解锁产物 | 前置条件 |
|---|---|---:|---|---|
| unlock_street_can | 解锁易拉罐 | 30 | 易拉罐 | 无 |
| unlock_street_cardboard | 解锁纸皮箱 | 120 | 纸皮箱 | 已解锁易拉罐 |

街道初始默认已解锁：

- 塑料瓶

## 5. 酒吧升级项

| 升级 ID | 名称 | 花费现金 | 解锁内容 | 前置条件 |
|---|---|---:|---|---|
| unlock_bar_scene | 解锁酒吧 | 300 | 酒吧场景、啤酒瓶子 | 无 |
| unlock_bar_wine | 解锁红酒瓶子 | 800 | 红酒瓶子 | 已解锁酒吧 |
| unlock_bar_baijiu | 解锁白酒瓶子 | 1800 | 白酒瓶子 | 已解锁红酒瓶子 |

酒吧未解锁前不可切换进入。购买“解锁酒吧”后，酒吧默认产出啤酒瓶子；红酒瓶子和白酒瓶子仍通过后续升级解锁。

## 6. 产物收益升级需求

产物收益升级用于提高已解锁产物的现金收益。

第一版可以先预留，不一定马上实现。

示例：

| 升级 ID | 名称 | 效果 |
|---|---|---|
| upgrade_plastic_value | 塑料瓶回收价提升 | 塑料瓶现金收益 +1 |
| upgrade_can_value | 易拉罐回收价提升 | 易拉罐现金收益 +1 |
| upgrade_glass_value | 玻璃瓶回收价提升 | 酒吧瓶子现金收益 +10% |

## 7. 刷新效率升级需求

刷新效率升级用于提高产物出现速度。

第一版可以先预留，不一定马上实现。

示例：

| 升级 ID | 名称 | 效果 |
|---|---|---|
| upgrade_street_spawn | 街道巡回路线 | 街道刷新间隔 -5% |
| upgrade_bar_spawn | 酒吧回收合作 | 酒吧刷新间隔 -5% |
| upgrade_screen_capacity | 大号回收袋 | 同屏产物上限 +1 |

## 8. 升级显示需求

- 主界面下方显示页签栏。
- 页签栏包含 `升级`、`场景` 和 `帮手` 三个页签。
- `升级` 页签显示产物解锁和产物效率类按钮。
- `场景` 页签专门显示场景解锁按钮。
- 升级按钮尽量小，适合在竖屏底部集中显示。
- 升级按钮需要显示名称、花费、效果、状态。
- 已购买升级项显示为已解锁。
- 现金不足的升级项显示为不可购买。
- 未满足前置条件的升级项显示为锁定。
- 点击购买成功后，立即刷新升级面板。

### 8.1 升级页签需求

- `升级` 页签是默认打开页签。
- `升级` 页签按场景显示产物升级项。
- 街道升级项显示街道产物解锁按钮。
- 酒吧升级项显示酒吧产物解锁按钮。
- 场景解锁项不显示在 `升级` 页签中。
- 当前场景的升级项优先显示在前面。
- 非当前场景的升级项也可以显示，但需要标注所属场景。
- 第一版按钮可以使用紧凑文本按钮，不强制做大卡片。

### 8.2 场景页签需求

- `场景` 页签只显示场景解锁按钮。
- 已解锁场景显示为已解锁。
- 未解锁但现金足够的场景可以购买。
- 现金不足的场景按钮不可购买。
- 场景购买成功后立即刷新页签状态，并允许通过主界面左右按钮切换。
- 第一版场景页签先显示“解锁酒吧”按钮。

## 10. 存档需求

存档中需要记录：

- 已购买升级 ID 列表
- 已解锁场景 ID 列表
- 已解锁产物 ID 列表

默认已解锁产物：

```text
street_plastic_bottle
```

默认已解锁场景：

```text
street
```

## 11. 代码需求

需要支持：

- 升级配置读取。
- 判断升级项是否可购买。
- 购买升级项。
- 扣除现金。
- 记录已购买升级。
- 记录已解锁场景。
- 记录已解锁产物。
- 通知产物生成系统刷新生成池。
- 保存和读取升级状态。

## 12. 验收需求

功能验收：

- 初始街道只会生成塑料瓶。
- 购买“解锁易拉罐”后，街道开始生成易拉罐。
- 购买“解锁纸皮箱”后，街道开始生成纸皮箱。
- 未购买“解锁酒吧”时，不能切换进入酒吧。
- 购买“解锁酒吧”后，可以切换进入酒吧，酒吧开始生成啤酒瓶子。
- 现金不足时不能购买升级。
- 已购买升级不会重复扣费。

技术验收：

- 场景和产物解锁状态可存档。
- 读档后已解锁场景和产物仍然生效。
- 生成系统不直接写死可生成产物。
- Godot editor 加载无报错。
